# 集群数据导出交互反馈

## 1. 问题

集群历史导出能够正常生成文件，但用户点击导出后，除按钮内的短暂状态变化外，缺少持续且醒目的处理反馈；时间范围快捷按钮也没有选中态，不容易判断刚刚应用了哪个时间窗口。

## 2. 修改内容

### 2.1 导出状态反馈

- 点击导出后立即显示持续的“正在导出”提示；
- 导出期间禁用表单、取消按钮和重复导出；
- 导出期间隐藏关闭按钮，并阻止通过弹窗关闭操作中断当前交互状态；
- 导出按钮显示旋转图标和 `aria-busy` 状态；
- 增加屏幕阅读器可感知的实时状态区域；
- 下载开始后将持续提示更新为成功提示，并显示实际文件名；
- 导出失败时将同一提示更新为具体错误信息。

历史 ZIP 由服务端流式生成，响应没有稳定的总字节数，因此本次使用不确定进度提示，不显示可能误导用户的百分比。

### 2.2 时间范围快捷按钮

- 点击“最近 15 分钟、1 小时、6 小时、24 小时、7 天”后保留选中态；
- 选中按钮使用更明显的视觉样式；
- 按钮同步设置 `aria-pressed`；
- 用户手动修改开始或结束时间后清除快捷范围选中态，避免显示与输入值不一致。

## 3. 兼容性

- 未修改导出接口、ZIP 结构和时间范围参数；
- 未新增依赖；
- 复用现有国际化文案和 Sonner 提示组件；
- 最新快照与时间范围导出使用相同的反馈流程。
