# 集群日期时间选择器样式对齐（第三阶段第三轮）

## 1. 开发目标

将集群状态相关的日期时间选择界面与“数据看板 → 筛选”中的日期时间选择器保持一致。本轮只调整组件和视觉样式，不改变时间范围的业务逻辑、展示内容、校验规则或接口参数。

## 2. 调整范围

- 一级、二级和三级趋势图的页面级时间窗口；
- 图表放大浮层中的独立时间窗口；
- 集群历史数据导出弹窗中的开始时间和结束时间。

## 3. 样式调整

- 复用数据看板筛选使用的 `DateTimePicker`；
- 日期通过统一的日历弹层选择，时间使用独立输入框；
- 开始时间和结束时间改为与数据看板一致的纵向排列；
- 快捷时间按钮采用相同的响应式两列/横向布局；
- 已选快捷时间使用主按钮和焦点环样式；
- 日期选择按钮、下拉图标、清除按钮及禁用状态使用统一组件规范。

## 4. 逻辑保持

- 原有相对时间选项及对应分钟数不变；
- 自定义范围仍精确到秒；
- 开始时间必须早于结束时间的校验不变；
- 遥测保存天数限制和可用数据起始时间不变；
- 页面级与放大图表的时间窗口仍相互独立；
- 相对窗口自动刷新、自定义窗口固定不移动的逻辑不变；
- 历史导出的快捷范围、可用历史裁剪和导出参数不变。

公共 `DateTimePicker` 新增可选的秒级精度、禁用状态和清除按钮控制。默认仍保持数据看板现有的分钟精度及可清除行为，因此其他页面不会发生行为变化。

## 5. 验证

- 新增秒级时间解析和格式化测试，确认秒值不会在样式替换后丢失；
- 更新导出弹窗布局回归测试，确认日期时间选择器保持数据看板的纵向排列；
- 集群导出、趋势范围相关测试通过；
- TypeScript、Oxlint 和生产构建通过。
